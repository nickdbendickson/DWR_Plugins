changelog=1.1.0 - DamSafety Core 1.0.0 - one shared damsuite (consolidation, 2026-11-08): this plugin no longer ships its own copy of the shared code. damsuite/ is a two-line shim onto the DamSafety Core plugin's damsuite package (DamSafety_Core/alias.py makes them the same module objects), and the shared window files (tokens, ui_widgets) are three-line shims onto DamSafety_Core/ui. The three-module mini damsuite (layout, suite_config) and the root suite_config.py / suite_fill.py / pack_convert.py are shims onto the Core's modules too. Install DamSafety Core first: metadata plugin_dependencies names it, so the QGIS Plugin Manager offers it when this plugin is installed. No tool, default or number changes.

Root README.md written.
