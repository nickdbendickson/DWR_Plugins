# damit_ai has moved

Heim (code triage) and Vor (literature) now live in one place only:
**[nickdbendickson/damit, folder `damit_ai/`](https://github.com/nickdbendickson/damit/tree/main/damit_ai)**.

The copy that was here had fallen behind. It lacked Heim's knowledge pack, the run watcher prompt,
the answer tests and about ten test files, and it had an older installer. Two copies drift because a
fix lands in one and not the other, so this one was removed (2026-11-22) rather than synced.

Nothing changes for an installed Heim or Vor. Install, update and report problems from the damit
repository; the install zips are built from there too. The tools still drive the DamSafety plugins
in this repository (`damchain`, `heim-test`), as before.

the damit repository).
