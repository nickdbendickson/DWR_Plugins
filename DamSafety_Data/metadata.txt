description=Keeps an offline copy of North Dakota structure and building-footprint data on this computer and downloads new versions when the sources change.
about=Downloads and maintains local North Dakota copies of the National Structure Inventory (NSI API; NSI 2026 and NSI 2022 merged into one layer by default), Microsoft building footprints, OpenStreetMap (Geofabrik), optionally FEMA/ORNL USA Structures, and optionally the USACE-NSI/nsi-generator source code. Each dataset is checked cheaply (checksum, ETag or latest commit) and only re-downloaded when it changed. Updates are staged and verified before replacing the local copy, so the data stays usable offline and an interrupted update never leaves partial files. Layers already in the project are reloaded after an update.

    1.8.0 - The offline pack builder gets the USGS 3DHP flowlines and waterbodies from the National Map 3DHP national file when the 3DHP web service is down. The hydro.nationalmap.gov service often answers HTTP 504 / 502 for a state-sized job (hundreds of tiles), so: if the National Map 3DHP file (CONUS FileGDB zip / .gdb / .gpkg, newest with "3dhp" in the name) is already in a 3dhp/ folder - the suite data folder's, or one beside the pack - the two hydro layers are cut out of it in minutes with no web request; otherwise the builder sends one small test request to the 3DHP service and, when that fails, downloads the national file once (resumable, from the National Map download store - a different server that stays up; kept for later builds and shared with the ND Data Updater) and cuts the layers from it.     1.7.0 - The offline pack is kept up to date, the way the ND Data Updater does it (merge step 3b): a new "Offline pack (keep up to date)" dataset (on by default) looks after the pack Build offline pack made, in the folder chosen there. Each check (at most once a day) reads the pack's manifest, builds the layers that are missing or not complete, fetches again the layers older than the refresh interval (Settings and status, default 30 days) and leaves the rest alone; both formats (ND_Dam_Suite_Pack and nd_offline_pack) are rewritten from the same download, in format 2 only the layers that changed. A layer that cannot be fetched keeps its old copy. Layers from your own DWR or HIFLD files are only rebuilt when missing (the build window now remembers those folders), never fetched over by age, and the land cover is not refreshed. It updates the pack the plugins read in place (each layer file is replaced by a rename), never starts a new pack (that stays in Build offline pack) and never touches a pack it did not build. One build of a folder at a time: the window and the updater share a lock in the build folder. Build offline pack with "Download everything again" and some layers ticked now rewrites only those layers in format 2. Test: tests/test_pack_refresh.py.
