about=Holds the one copy of the code the DamSafety plugins share: damsuite (dam records, the REG_05.2026 Fig. 5.1 / 5.2 curve table, the suite settings file, the offline data pack reader and builder, the pre-solve gate, version checks between the plugins) and the suite's window files and layer styles. Each DamSafety plugin's damsuite/ is a two-line shim onto this plugin, so a fix made here reaches every plugin at once and no two plugins can disagree. Every other DamSafety plugin lists this one in plugin_dependencies: QGIS offers to install it when one of them is installed.

changelog=1.0.0 (2026-11-08; consolidation: one shared damsuite) First release. damsuite 1.18.9 (was vendored byte-identically into DamSafety Hazard, Runner, Screening and Data, with three modules in Setup, by tools/sync_damsuite.py against a pin) and the shared window files (was tools/sync_ui.py copies) move here, with the suite's QML layer styles (ui/styles/). alias.py makes `<Plugin>.damsuite` the same module objects as `DamSafety_Core.damsuite`, so the plugins' relative imports keep working with no second copy. damsuite.selfcheck() compares this plugin's damsuite files with its FILES.json; each plugin calls it at start-up as before. Tests: tests/test_alias.py (both import forms, identity, reload, the ImportError when this plugin is missing), tests/test_ui_shim.py.
